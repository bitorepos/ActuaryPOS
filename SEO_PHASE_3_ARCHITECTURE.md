# SEO Phase 3 architecture

Audit date: 2026-09-09. Scope: repository implementation, not production deployment.

## Existing architecture and evidence

The current routes, Phase 2 local CMS inventory (5 published records), and feature/industry plans contain no dedicated commercial landing pages. Existing `/`, `/pricing`, `/c/page/{page}`, blogs, and `/docs/{slug}` are retained. The production pricing fetch failed (404 reported by the fetch service); production CMS records and Advanced Module availability still require deployment reconciliation. Pricing uses database products/categories via `PricingController`; no prices or entitlements are copied into these pages or changed.

The CMS layout already supplies metadata, social tags and JSON-LD. Reuse it and its header, navbar and footer, with one landing-page template. Extend its breadcrumb hierarchy instead of adding duplicate schema. The sitemap already filters CMS noindex and noncanonical content. Documentation has a public, availability-filtered registry; use that registry for outbound guide links. Existing documentation remains instructional.

## Page decisions before implementation

All CREATE rows pass the content gate: a distinct commercial evaluation intent, concrete code/guide evidence, unique operational copy and useful related links. Secondary features are consolidated into relevant pages until enough independent content warrants another URL. No search-volume figures are claimed. Every new detail page links to its hub, pricing/contact, related pages and available guides. Industry pages describe business workflows; feature pages explain module operation.
